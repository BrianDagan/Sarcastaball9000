Settings

Spotify sign-in

Use your own Spotify Premium account and developer app. Enter its Client ID; no client secret is needed. Add this page's URL in the Spotify dashboard (opens in a new tab).

Sign-in, privacy and logout notes

This site's files are public. Your Spotify Development Mode allowlist controls API access; keep only the intended account on it. Protected sign-in requires Web Locks on HTTPS or loopback HTTP.

Only explicitly confirmed logout may clear all app data. Reloads, rejected sign-ins and token/network failures preserve the library, edits, settings and valid remembered sign-in.

Logout offers export, cancellation or explicit discard. Revoke the Spotify grant separately in Spotify account settings if needed.

SQLite library

Export your own SQLite library from Sports Audio DJ, then choose it here. Keep an independent original backup; no starter database is included.

All file types are shown to avoid device-specific filtering. The filename does not matter; only a compatible SQLite database loads.

Active Spotify device

Open Spotify on the output device, play any song briefly, then refresh and choose it.

iPad keep-awake

For the selected device whose name contains "iPad", visible-page idle playback, Pause and Stop use the ten-minute silence track. Resume restores the paused song. Keep Repeat off. Closing or hiding the app stops renewal, so it cannot guarantee silence remains active; Queue or Autoplay can still act if renewal is missed.

This is the normal iPad behavior. The top-right ms display shows a play icon for active song playback and swaps it for the small spinning baseball only after Spotify confirms idle silence is playing. Turn this setting off only when you deliberately want ordinary Spotify Pause/Stop behavior.

If Spotify stops listing the selected iPad, the error offers Open Spotify to wake iPad. iOS requires your tap. Spotify may only open the silence track page, so tap Play if needed and manually return here; Sarcastaball then makes one fresh recovery check. It cannot launch Spotify automatically, force autoplay or switch back to this app.

Keep the iPad volume at least one notch above zero. Spotify on iPad can pause at zero volume; the silence track itself has no audible content. Sarcastaball reads reported volume only for diagnostics and never sends iPad volume commands.

Share opens the system sheet for AirDrop, Files or another destination. Nothing is sent automatically. The generated JSON excludes credentials, Client IDs, account/device/track identifiers and names, database contents, storage dumps and raw Spotify responses.

Playback defaults

Browser volume and volume fades are unavailable on iPad/iPhone or a device that disallows them. Use physical or Spotify controls. Saved values and end-cue pauses remain available.

Used when starting a track unless that tile has its own value.

Network playback and browser timers are best-effort. A tile's own fade value overrides these defaults.

Display and app

Force refresh saves recovery, reloads the published app assets, and preserves Spotify sign-in, selected device, library, unsaved edits and settings.

The source database defaults to red; this changes only the web app's default.

A separate browser or Home Screen app may use separate storage. Keep a database export and sign in/import there if needed; your current browser's data is not erased. Full screen does not guarantee background playback or cue timing.

Export before logout

Logging out erases this app's browser database, unsaved edits, settings and sign-in. Original files and previous downloads are never deleted.

Export your current working database first, or explicitly discard the browser copy. Cancel keeps your work.

Other DJDad tabs on this same origin will also be cleared. Export any separate work in those tabs first.
