Setup

1. Spotify auth

You need your own Spotify Premium account and developer app. Enter that app's Client ID, then log in. No client secret is needed. In your Spotify dashboard (opens in a new tab), add this page's URL as a Redirect URI:

This website's files are public. Your Spotify app's Development Mode allowlist controls API access, not access to this page. Keep only your intended account on that list.

Protected sign-in requires Web Locks in a secure browser context: HTTPS or loopback HTTP. Browser and native-app compatibility have not been comprehensively verified.

Only explicitly confirmed logout may clear all app data. Startup, reload, rejected sign-in attempts and token/network failures must preserve your library, edits, settings and valid remembered sign-in. Reconnection may be needed if Spotify rejects authorization; keep your Client ID and library.

Logout offers export, cancellation or explicit discard before erasing this app's cached database, edits, settings and credentials. Verify any download before confirming erase. To revoke the Spotify grant too, remove the app in your Spotify account settings.

2. Database

Export your own SQLite library from Sports Audio DJ, then pick the .sqlite file. Keep an independent backup of the original. Specific Sports Audio DJ versions have not been verified; no starter database is included.

All file types are shown to avoid device-specific filtering. The file can have any name; only a compatible SQLite database will load.

3. Active device

Open Spotify on the device you want to control, play any song briefly, then refresh.

Playback

Automatic only for the selected Spotify device whose name contains "iPad". While this page is visible, idle playback, Pause and Stop use the ten-minute silence track. Resume restores your paused song. Turn this off to stop idle silence. Keep Repeat off in Spotify; queue or Autoplay settings can still play other audio after the last silence track ends. Closing or hiding this page stops renewal, not necessarily Spotify playback.

Browser volume and volume fades are unavailable on iPad/iPhone or a device that disallows them. Use physical or Spotify volume controls. Saved values are retained, and end cues still stop playback.

Used when starting any track. Overrides the value stored in the DB.

Fade-out runs near the end cue. Spotify network commands and browser scheduling are best-effort: exact silence timing and background-tab stops are not guaranteed. A tile's own fade value overrides these defaults.

Export before logout

Logging out erases this app's browser database, unsaved edits, settings and sign-in. Original files and previous downloads are never deleted.

Export your current working database first, or explicitly discard the browser copy. Cancel keeps your work.
